ARCADIA LUXURY BETA — Android / Pydroid 3

ВАЖНО
- Это обновлённая совместимая версия проекта на основе присланных index.html, style.css, app.js и SQLite.
- Файл server.py в присланном наборе отсутствовал, поэтому серверная часть подготовлена заново по описанному API. Это не восстановление старого исходного server.py.
- Не отправляй BOT_TOKEN в чат и не загружай его в GitHub.
- Монеты демонстрационные, не имеют денежной стоимости. Реальные платежи не подключены.
- GitHub Pages не запускает Python. Для игры нужен работающий Flask-сервер с HTTPS-адресом.

ЗАПУСК НА ANDROID
1. Распакуй архив в отдельную папку, например:
   /storage/emulated/0/ARCADIA_LUXURY/
2. Открой Pydroid 3 → Terminal.
3. Установи библиотеки:
   pip install -r /storage/emulated/0/ARCADIA_LUXURY/requirements.txt
4. Настрой BOT_TOKEN как переменную окружения в своей среде запуска. Не вставляй токен в публичные файлы и не отправляй его в чат.
5. Запусти:
   cd /storage/emulated/0/ARCADIA_LUXURY
   python server.py
6. Для локального предпросмотра открой на том же телефоне:
   http://127.0.0.1:8080/
7. Проверка API:
   http://127.0.0.1:8080/api/health

TELEGRAM
- Для настоящего Telegram Web App нужен публичный HTTPS URL, который ведёт на этот Flask-сервер.
- BOT_TOKEN должен быть доступен процессу как переменная окружения BOT_TOKEN. Без токена проверка Telegram initData не проходит.
- GitHub Pages может хранить файлы, но не заменяет Flask-сервер.
- Этот пакет пока не запускает polling-бота и не создаёт кнопку меню через Bot API. Сначала проверь сервер и Web App; подключение управления ботом — следующий этап.

ЧТО ЕСТЬ В ЭТОЙ BETA
- Обновлённый мобильный тёмно-фиолетовый и золотой интерфейс.
- Пять демонстрационных наборов.
- Открытие 1–10 паков за раз, свайп-вскрытие и перелистывание карточек.
- Common, Rare, Epic, Legendary, Mythic, Limited.
- Общая последовательная нумерация карточек вида #1, #2, #3 без ведущих нулей.
- Серверное списание монет и ежедневная награда 200 монет раз в 24 часа.
- Проверка подписи Telegram WebApp initData на сервере.
- Локальный демо-режим только для loopback-адреса.

ОГРАНИЧЕНИЯ И СЛЕДУЮЩИЕ ЭТАПЫ
- Названия и изображения карточек сейчас демонстрационные; лицензированные изображения не включены.
